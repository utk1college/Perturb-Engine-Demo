Each question goes through three kinds of rewording. Lexical swaps a word for an exact synonym. Syntactic restructures the sentence with the same words. Pragmatic changes what surrounds the question: a neutral opener, an instruction before it, an unrelated sentence after it, or a keyboard typo.

A rewrite is kept only if it passes the hard checks (numbers, negations, protected text untouched), stays close in meaning by SBERT, and both versions imply each other by an NLI model. Pragmatic additions are checked one way only (the rewrite must still imply the original), since they add words on purpose. Anything that fails is shown as rejected, with the reason.
